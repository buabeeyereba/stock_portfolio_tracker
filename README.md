# Buabee's Stock Portfolio Tracker 📈

A simple, interactive command-line Python script designed to help you track stock investments, calculate your portfolio's grand total value, and save your summary to a local file.

Developed as part of the CodeAlpha Internship Program. 🚀

About CodeAlpha Internship 💼

This project was built to fulfill task requirements during the CodeAlpha Virtual Internship, demonstrating fundamental Python concepts such as loops, conditionals, user input handling, and file I/O operations.

## Features ✨

**Interactive CLI:** Prompts you to input stock names and quantities in a continuous loop.

**Pre-set Prices:** Includes quick sample pricing for selected stocks (AAPL: $180, GOOGL: $500).

**Automatic Calculation:** Multiplies stock quantity by its price and aggregates your overall portfolio worth.

**File Export:** Automatically exports the final portfolio summary to a local portfolio text file.

## Prerequisites 🛠️

**Python 3.x** installed on your machine.

## How to Run 🚀

Clone or download this repository.

Open your terminal or command prompt in the project directory.

Run the script using Python:
```bash
python portfolio.py
```
